# hurt

Planning a Klingon-language rendition of **Hurt** in the style of Johnny Cash's cover. **Planning only; no audio produced.**

The intended result preserves the chosen Cash recording's backing, timing, melody, arrangement, emotional delivery, and recognizable vocal character while changing the sung language to Klingon. An identical result is unproven. Any eventual synthetic performance must be permission-cleared and described as an **authorized reinterpretation**, never an authentic Johnny Cash performance.

- [Production plan](PLAN.md): feasibility, permissions, workflow, pilot, quality gates, effort, costs, and decisions awaiting production approval.
- [Source register](SOURCES.md): primary and official research, accessed September 20, 2026, with evidence limits.

The recommended next production step, **only after separate approval**, is a small pilot using newly written or user-supplied authorized material and a consenting singer. Passing that pilot would not establish permission or capability to reproduce Cash's voice.

This public repository contains planning documents only. It contains no lyrics or translations, recordings or stems, voice models, production software, or private permission records. Publication of this plan does not authorize song production, purchases, outreach, or release.
